🗡️ 长矛区（19–25 · 操练册） ​

长矛不是「知识点」，而是「验收物」。造出一件就离 D4 近一步，凑齐两把长矛加一条证据链，简历才经得起三十分钟追问。

新章交付物（验收标准）
19 · 深度分级框架能用 D1–D5 给每一项能力定坐标，并说出下一级的具体交付物
20 · 训练计划与里程碑24 个月三阶段执行表；每月 journal 复盘一次；验收物清单 10 项填绿
21 · AI 模型层与推理优化mini-GPT 实证 + LoRA 微调报告 + vLLM 压测 + mini-vLLM 调度器仓库（连续批处理 + KV Cache 分页）；起点：骨架代码
22 · 分布式内核mini-Raft（带正确性测试，套件见 测试用例集）+ miniLSM + minimq 三件引擎仓库
23 · 项目实操册项目一（SaaS 后端，脚手架见 saas-backend-scaffold）：真实用户 + QPS/P99/成本 + 故障复盘
项目二（RAG，工具见 评估工具链）：golden set 评估报告 + 红队报告 + 成本账单
24 · 证据与影响力≥1 个非 docs PR 被 merge + 10 篇深度文 + 简历每条 bullet 能被追问三层
25 · 算法军械库100 天轨道（medium 20min AC 率 >70%）；14 类题单目录 + 设计并发池

为什么必须有这三样 ​

  • 算法：国内大厂单程票，八股和作品再好都绕不过
  • 两个旗舰项目：「做过什么」不靠描述，靠 QPS/P99/成本/故障这些数字
  • 评估与安全：RAG 谁都会搭 demo，拼的是「检索质量怎么量化、幻觉怎么兜底」的工业级方法
